Top recurring / critical issues observed
Missing DEV_COOKIE_NAME environment variable (frequent): causes IllegalStateException when code tries to read session cookie name or create Cookies, leading to 500/UnhandledException. Fix: set DEV_COOKIE_NAME before requests (development SSoT env resolution).
UnauthorizedException: Account not approved — multiple login attempts for users not yet approved. Fix: either approve test user in DB or adjust test flow to approve before login.
Cookie name unresolved token usage: attempts to use literal token string ("${DEV_COOKIE_NAME:?missing}") created invalid Cookie → causes IllegalArgumentException from Jakarta Cookie validation.
JWT secrets are present in some calls but when inconsistent across runs they produce validation/signature errors (observed earlier in the session). Ensure both DEV_JWT_ADMIN_SECRET and DEV_JWT_STUDENT_SECRET are stable and identical across processes that sign/verify tokens.
Quick remediation checklist
Export DEV_COOKIE_NAME (e.g., export DEV_COOKIE_NAME=cegm_dev_session) in the environment that runs the backend.
Ensure DEV_JWT_ADMIN_SECRET and DEV_JWT_STUDENT_SECRET are set and length >= 32 chars in the environment used for running backend and any scripts.
