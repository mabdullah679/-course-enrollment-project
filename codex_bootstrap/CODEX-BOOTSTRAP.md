## 🎯 Project Purpose

The Course Enrollment & Grade Management System is a modular, full-stack educational backend built for real-world DevOps training and deployment workflows.

Your job? Provide insights, locate files, help debug config issues, and assist with shell or API-related scripting.

| Folder       | Description                              |
